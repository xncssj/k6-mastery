# 第 02 篇边界探针记录（2026-10-16）

本文件归档第 02 篇复审修订所用的 5 枚边界探针（探针 A—E），用于实证正文三处口径：init 求值计数与第 6 次归属、退出码 107 的边界（迭代内抛错）、teardown 的执行条件（主动中止）。探针不是跟练脚本，不进入教学交付清单；读者需要复现时，把对应脚本全文存成本地 `.js` 文件运行即可。

## 运行环境与收录规则

- 操作系统：Windows（amd64）；k6 v2.2.0（commit/00a9a1b7f5, go1.26.5）——与《本地实跑记录-2026-10-14.md》同一版本。
- 全部为纯内存脚本、零请求，不需要被测服务；执行目录为本机临时目录。
- 每枚探针收录：脚本全文（逐字）＋console／错误日志行（逐字，含时间戳）＋末行退出码；k6 启动 banner、进度条刷新行与结果摘要小节对判断无增量，从略。日志行中 k6 堆栈的本机绝对路径前缀统一归一为 `file:///<本机临时目录>/`（发布卫生），报错正文、脚本名、行列号、时间戳与退出码逐字未动。
- 探针 A—D 在同日两个时点（14:26 与 16:55 前后）各跑过一次，init 计数、关键现象与退出码两次一致；探针 E 跑一次。下文收录复跑（16:55—16:56）输出。

## 汇总表

| 探针 | 形态 | init 求值次数 | 关键现象 | 退出码 |
|---|---|---|---|---|

## 探针 E：test.abort() 主动中止不拦 teardown

```javascript
import exec from 'k6/execution';

export const options = { vus: 1, iterations: 2 };
console.log('[init] eval');
export default function () {
  console.log('[default] before abort');
  exec.test.abort('教学探针：主动中止');
}
export function teardown() {
  console.log('[teardown] run');
}
```

```text

time="2026-10-16T16:56:52+08:00" level=info msg="[init] eval" source=console
```

结论：default 内 `test.abort()` 主动中止后，`[teardown] run` 照常打印（其紧前仍有 1 次 init 求值，与探针 B 的 teardown 环境一致；紧后 1 次为摘要阶段），整轮以 108（ScriptAborted）退出。与官方 k6／execution 口径一致：「中止测试不会阻止 teardown() 执行」。第 2 次迭代未再执行（abort 即停）。
